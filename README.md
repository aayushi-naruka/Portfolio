# Portfolio

## Aayushi Naruka

Personal portfolio built with React and Vite. The site is published on GitHub Pages:

https://aayushi-naruka.github.io/Portfolio/

## Local development

```sh
npm ci
npm run dev
```

## Production build

```sh
npm run build
npm run preview
```

Every push to `main` builds and deploys the site through GitHub Actions. The Vite base path is set to `/Portfolio/` in GitHub Actions and `/` for local development.
